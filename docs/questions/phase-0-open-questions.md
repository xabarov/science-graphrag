# Открытые вопросы после Phase 0

Phase 0 **не блокируется** ответами ниже — это отложенные решения для последующих фаз.

## Технологии хранения и рантайма

- Конкретные СУБД для графа и вектора, оркестрация контейнеров, версии — зафиксировать при старте Phase 1 / инфраструктуры.
- Выбор HTTP-стека и языка реализации сервисов (если отличается от общего решения монорепо).

## Продукт и границы MVP

- Нужен ли отдельный документ UX / приоритизация экранов до начала Phase 6 — по готовности backend-контрактов.
- Политика лицензий PDF и хранения full text в пилоте.

## Внешние API

- Квоты и ключи OpenAlex / Crossref / ORCID / ROR; offline-деградация — детализировать в runbooks Phase 7.

При появлении блокирующих вопросов — вынести в новый ADR или раздел roadmap.
