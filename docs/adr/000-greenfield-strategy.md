# ADR 000: Greenfield + selective reuse (референс osint-gr)

- **Status**: Accepted
- **Date**: 2026-03-30

## Context

Нужно создать GraphRAG для scholarly-корпуса с явной онтологией, extraction и UX под исследователя. Варианты:

1. **Copy-first** — форк или копия близкого по стеку репозитория с заменой домена.
2. **Greenfield + selective reuse** — новый репозиторий; из внешних проектов брать только паттерны (docs, ADR, тесты, структура модулей).

Риск copy-first: перенос доменно-специфичной логики, скрытого технического долга и несовместимых абстракций.

## Decision

Выбран **greenfield + selective reuse**.

**Референс по процессам:** проект `osint-gr` — структура `docs/`, ADR, семейства бенчмарков, стратегия тестирования и идея CI/gates. Использовать как образец **организации работ**, не как источник кода scholarly-слоя, онтологии OSINT или готовых benchmark-фикстур.

**Явно не переносим без перепроектирования:**

- доменную онтологию и extractors;
- frontend-сценарии «расследования»;
- eval-кейсы и фикстуры под другой домен.

## Consequences

- Репозиторий и модули проектируются под `Work`, `Author`, цитирование, claims и т.д. с нуля (см. [idea.md](../idea.md), [roadmap](../roadmap.md)).
- Документация и ADR ведутся с первых фаз; решения о стеке хранилищ и фреймворках — отдельными ADR при появлении реализации.
- Дублирование кода с `osint-gr` не является целью; совпадения возможны только на уровне общих библиотек/паттернов по явному решению.
