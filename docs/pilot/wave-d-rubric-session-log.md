# Wave D pilot — subjective usefulness rubric (session log)

Template for closing the **Subjective usefulness** row in [wave-d-exit-record.md](wave-d-exit-record.md).  
Each session: one researcher, same signed-off corpus and API base as engineering KPIs.

## How to run a session

1. Confirm corpus path / ingest matches [pilot-corpus-wave-d.md](../runbooks/pilot-corpus-wave-d.md).
2. Open UI: Corpus → Workspace → Graph → Ask (or paths from [user-journeys-retrieval-v1.md](../runbooks/user-journeys-retrieval-v1.md)).
3. Score **1–5** per criterion (1 = not useful, 5 = very useful); add short notes.
4. Paste scores into the table below (or attach a dated copy).

## Aggregate (pilot GO rule)

- **GO:** ≥2 completed researcher rows and mean score ≥3 on all five criteria (or documented waiver in exit record).
- **NO-GO:** serious trust issues on citations (mean <2) until triage in exit record.
